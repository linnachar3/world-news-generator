# 📰 SillyTavern 信息中心插件

一个悬浮球插件，为 [SillyTavern] 酒馆提供独立的世界新闻、本地快讯和角色社媒生成功能。基于当前角色、世界书和聊天历史，调用 AI 生成符合世界观风格的动态内容。

## ✨ 主要特性

- **可拖拽悬浮球**：一个报纸图标（📰），拖动到任意位置，单击打开主窗口。
- **三个信息标签页**：
  - **世界新闻** – 根据世界书生成今日世界报头条。
  - **本地新闻** – 生成角色所在地区的本地事件。
  - **个人社媒** – 模拟角色和用户发布的社交动态。
- **风格适配**：AI 自动感知世界观（古风、西幻、科幻等），用对应的文风写作。
- **独立 API 设置**：可配置任意 OpenAI 兼容接口，一键获取模型列表。
- **复古纸片 UI**：衬线字体、直角边框、噪点纹理。
- **实时上下文**：自动读取当前角色、用户名、角色世界书条目数和聊天历史。

## ⚙️ 使用说明

1. 点击悬浮报纸图标，打开信息中心。
2. 首次使用前，点击标题栏的 `𖥕` 设置按钮，填写 API 信息：
   - Base URL（例如 `https://api.openai.com/v1`）
   - API Key
   - 点击「获取模型列表」拉取可用模型，或手动输入模型 ID。
3. 保存设置。
4. 切换到相应标签页，点击「↻ 生成…」按钮，等待 AI 生成内容。
5. 生成的内容会以报纸或社媒卡片形式展示，切换标签不会丢失。
6. 设置面板底部可展开查看当前上下文信息（角色、世界书条数、聊天条数）。

## 🛠️ 技术细节

- 纯前端扩展，不修改酒馆核心代码。
- 通过 `SillyTavern.getContext()` 获取实时上下文。
- 使用 `localStorage` 保存 API 配置。
- 所有 UI 均为自建，不依赖外部框架。
- 兼容 OpenAI、Claude、DeepSeek 等所有兼容 `/v1/chat/completions` 的接口。
